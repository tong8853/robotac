# 模型改进进程

## 2026-05-14 图像观测版本训练

### 代码修改

#### 1. 新增文件

**`explore/observation_wrapper.py`** - 图像格式转换包装器
- 实现 `ImageObservationWrapper` 类，将 MetaDrive 图像格式转换为 SB3 兼容格式
- 输入格式: `(H, W, C, history)` → 输出格式: `(C*history, H, W)`
- 支持多帧历史图像拼接与归一化
- 同时保留 state 向量用于辅助决策

**`explore/test_image_env.py`** - 图像环境测试脚本
- 用于快速验证图像观测配置是否正确

#### 2. 修改文件

**`explore/train_ppo.py`**
- 导入 `ImageObservationWrapper` 和 `RGBCamera`
- 环境配置改为 `image_observation=True`
- 添加 `sensors` 配置和 `norm_pixel=True`
- 使用 `ImageObservationWrapper` 包装环境
- 策略从 `MlpPolicy` 改为 `MultiInputPolicy`（适配 Dict 观测空间）
- 删除旧的不兼容模型文件

**`explore/test_ppo.py`**
- 同步更新为图像观测配置
- 添加 `ImageObservationWrapper` 包装

**`explore/visualize_ppo.py`**
- 同步更新为图像观测配置
- 添加 `ImageObservationWrapper` 包装

**`explore/config.yaml`**
- `image_observation: false` → `image_observation: true`
- 添加 `sensors` 和 `vehicle_config` 配置

### 问题分析

1. **泛化失败**: 训练成功但测试失败，说明过拟合
2. **速度过慢**: 车辆平均速度仅 0.70 km/h，行驶异常缓慢
3. **延迟波动**: 最大推理延迟 704ms，偶尔超标

### 下一步改进方向

1. **地图随机化** - 使用 `generate_type: "big_block_sequence"` 增加场景多样性
2. **增加训练步数** - 500k-1M 步，让 CNN 充分学习
3. **课程学习** - 从简单场景逐步增加难度
4. **调整超参数** - 减小学习率，增加 batch_size
5. **多环境并行** - `n_envs=4` 加速训练
