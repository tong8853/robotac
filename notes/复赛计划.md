# 复赛准备计划

> 本计划针对复赛强化学习赛道，目标：训练模型并在官方嵌入式环境提交。

---

## 阶段一：环境搭建（1-2天） ~ 已完成

- [x] 确认本地 Python 环境（robotac conda）能正常启动 MetaDrive
- [x] 安装 PyTorch GPU 版（已安装 CUDA 11.7）
- [ ] 安装 stable-baselines3：`pip install stable-baselines3`
- [ ] 确认 Kaggle/Colab GPU 环境可用
- [ ] 编写环境测试脚本，确保 `env.step()` 正常工作

## 阶段二：数据采集（3-5天）

- [ ] 编写手动控制脚本采集轨迹数据（`observation → action` 对）
  - 摄像头图像（320×180）
  - 对应动作（steering, throttle）
  - 保存为 `.npz` 或 `.h5` 文件
- [ ] 批量采集：不同地图 seed，每局多个 episode
- [ ] 数据量目标：至少 10 万帧覆盖多种路况
- [ ] 验证数据完整性（无缺失帧、动作范围合理）

## 阶段三：模型训练（5-7天）

- [ ] 选择算法：PPO（stable-baselines3 内置）
- [ ] 搭建训练循环
  - 环境创建
  - CNN 策略网络（处理图像）
  - 奖励函数设计（到达终点+，撞车-，压线-）
- [ ] 本地训练验证（几千步看是否收敛）
- [ ] 云 GPU 训练（Kaggle/Colab，10万+步）
- [ ] 保存模型权重 `.zip` 或 `.pth`

## 阶段四：推理与封装（2-3天）

- [ ] 编写推理脚本：从模型输出动作
- [ ] 对齐输入输出接口（与官方 workspace 规范一致）
- [ ] 测试推理实时性（每步 < 0.1s）

## 阶段五：嵌入式环境适配（2-3天）

- [ ] 在官方 `python-3.7.0-embed` 环境测试运行
- [ ] 对齐库版本（torch、numpy 等）
- [ ] 删除多余依赖
- [ ] 确认无网络请求
- [ ] 本地推理测试通过

## 阶段六：提交（1天）

- [ ] 打包模型权重 + 推理脚本 + 依赖列表
- [ ] 按官方要求格式提交到 workspace 目录
- [ ] 本地跑通完整流程（reset → step 循环 → 输出动作）
- [ ] 测试 `启动仿真环境.bat` 能正常运行

---

| 阶段三 | 模型收敛，到达终点 |

## 注意事项

- 数据采集时固定地图（seed=21），提交前用不同 seed 测试泛化能力
- 每次修改后本地跑通再提交
- 保存好训练日志，方便复现
