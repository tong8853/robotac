# ROBOTAC 复赛依赖安装

## 环境要求
- Python 3.7+
- conda 环境：robotac

## 安装命令

### 核心依赖（一次性安装）
```bash
pip install metadrive gymnasium numpy opencv-python matplotlib pillow shapely cloudpickle tqdm pyyaml pyparsing
```

### 图形渲染依赖
```bash
pip install panda3d pygame
```

### 完整安装（推荐）
```bash
pip install metadrive_simulator==0.4.3 gymnasium==0.28.1 numpy==1.21.6 opencv-python==4.12.0.88 matplotlib==3.5.3 Pillow==9.5.0 shapely==2.0.7 cloudpickle==2.2.1 tqdm==4.67.1 pyyaml pyparsing panda3d==1.10.15 pygame==2.6.1
```

### 强化学习所需（后续训练用）
```bash
pip install torch stable-baselines3
```

## 验证安装
```bash
python -c "import metadrive; print(metadrive.__version__)"
python -c "import gymnasium; print(gymnasium.__version__)"
python -c "import cv2; print(cv2.__version__)"
```
