## 奖励函数设计（参考）

```python
def compute_reward(vehicle_state):
    # 速度奖励：越快越好
    speed_reward = vehicle_state.speed  # km/h

    # 中心线奖励：越接近中心得分越高
    lateral_reward = 1.0 - abs(vehicle_state.lateral_distance)

    # 碰撞惩罚：发生碰撞大幅扣分
    collision_penalty = -100 if vehicle_state.crashed else 0

    # 压线惩罚
    off_road_penalty = -10 if vehicle_state.off_road else 0

    total_reward = speed_reward * 0.3 + lateral_reward * 0.5 + collision_penalty + off_road_penalty

    return total_reward
```
